# TriComposer 功能详录

> 版本：0.1.0 ｜ 平台：DSH web profile ｜ 记录日期：2026-08-24

## 1. 面板结构

面板挂载在会话输入卡片正上方（`conversation.input.dock` 槽位，list 型叠加，session 作用域），由标题栏 + 输入区组成。

### 1.1 标题栏（常驻）

- 名称：「三段输入」
- 格式提示：`台词“” · 动作【】 · 心理（）`
- 右侧控件：简要 / 详细（视图切换）、折叠 / 展开

### 1.2 输入区（三个字段）

| 字段 | 语义 | 占位提示 |
|---|---|---|
| 台词 | 玩家说出的话，NPC 可听到 | 说出去的话，NPC 听得到 |
| 动作 | 玩家做出的动作，NPC 可看到 | 做出的动作，NPC 看得到 |
| 心理 | 玩家内心想法，仅叙事者可见 | 内心想法，仅叙事者知道 |

## 2. 视图模式

### 2.1 简要（横向）

- 三个单行 `<input>` 横向排列，标签在框内左侧
- 任一框内按 Enter 发送
- 适用：短句、快节奏对话

### 2.2 详细（纵向）

- 三个多行 `<textarea>` 纵向堆叠，每格上方显示字段名 + 语义提示
- 文本框支持纵向拖拽扩高（`resize: vertical`，默认 2 行高）
- Ctrl+Enter 发送
- 适用：长段落、需要通读检查全文

### 2.3 折叠

- 折叠后仅保留标题栏（高度约一行），输入区完全隐藏
- 展开恢复至当前视图模式

### 2.4 状态持久化

- 视图模式与折叠状态写入 `localStorage["dsh-rp-composer-ui"]`
- 刷新、重开页面均保持

## 3. 组装与发送

### 3.1 组装规则（assemble 函数）

不使用符号包裹，用中文说明每个成分，提升模型理解的容易程度：

```
非空台词 → 台词（我说出口的话，NPC 能听到）：<内容>
非空动作 → 动作（我做出的行为，NPC 能看到）：<内容>
非空心理 → 心理（我的内心想法，NPC 无法感知，不要在正文中引用或回应它）：<内容>
按 台词→动作→心理 顺序逐行拼接，首部加引导行
"本轮我的输入包含以下成分，请严格区分，不要混为一谈："；全部为空则不发送。
```

示例：台词=`我该走了。`，动作=`放下茶杯`，心理=`其实还想再待一会`
输出：
```
本轮我的输入包含以下成分，请严格区分，不要混为一谈：
台词（我说出口的话，NPC 能听到）：我该走了。
动作（我做出的行为，NPC 能看到）：放下茶杯
心理（我的内心想法，NPC 无法感知，不要在正文中引用或回应它）：其实还想再待一会
```

### 3.2 发送管线

1. `props.inputActions.setDraft(组装文本)` —— 写入会话草稿
2. `props.inputActions.submit()` —— 走标准提交（InputMachine 状态机 → default-sink → session.prompt）
3. 发送后清空三个输入框

行为等价于用户手敲全文后点击发送：会话日志、撤回、重发、队列全部一致。

## 4. 集成与兼容性

- **零侵入**：list 型槽位叠加，默认输入框、Agent RP「开始游玩」、便携酒馆面板等其他插件功能均不受影响
- **协议配套**：输出格式与 Gent 模式预设的【输入解析协议】完全对齐（台词“” / 动作【】 / 心理（）），形成"输入约定 → 机器可解析 → NPC 感知边界"闭环
- **无后端**：Node 半为空壳插件（roster 加载需要），全部逻辑在浏览器端

## 5. 技术实现摘要

- 文件：`package.json`（exports + `dsh.bundle.patch` + `dsh.client` 声明）、`cordis.patch.yml`（insert roster 行）、`dsh.plugin.json`、`lib/index.js`（空壳）、`lib/client.js`（全部 UI 逻辑，约 170 行，React createElement 手写，无构建步骤）
- 客户端加载：`window.__ModuleLoader__.load({ id, factory })` CJS 包装，`react` 由 shell 种子模块提供
- 服务注入：`inject: ["slots"]`，`slots.inject("conversation.input.dock", …)` 等待槽位声明后注册（与插件加载顺序无关）
